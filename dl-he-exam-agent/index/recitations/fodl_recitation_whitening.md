# תרגול: הלבנה (תרגול 5)
- **File:** materials/recitations/fodl_recitation_whitening.pdf
- **Related lectures:** lecture_03_optimization_1 (ירידת גרדיאנט, מספר תנאי); רקע ל-lecture_01_three_pillars ולחלק העיבוד-המקדים של dl_standard_practices
- **Summary:** גוזרת הלבנה (whitening) — התמרה אפינית $Y = AX + b$ הממפה וקטור אקראי $X$ בעל תוחלת $\mu$ ושונות משותפת $\Sigma$ לתוחלת אפס ולשונות משותפת יחידה. פותרת את אילוצי ההגדרה לקבלת הלבנת PCA $A_{\mathrm{PCA}} = D^{-1/2}U^\top$ דרך הפירוק העצמי $\Sigma = UDU^\top$, מראה שמטריצת ההלבנה יחידה רק עד כדי גורם אוניטרי משמאל, ומגדירה הלבנת ZCA ($R = U$) כבחירה השומרת על מבנה הנתונים המקוריים (חיונית לקלטי CNN). מסתיימת בדוגמת רגרסיה לינארית המראה מדוע הלבנה עוזרת לאופטימיזציה: ירידת גרדיאנט מתכנסת בקצב הנשלט על ידי מספר התנאי $K = \lambda_{\max}/\lambda_{\min}$ של $XX^\top$, ונתונים מולבנים נותנים $K = 1$, כלומר התכנסות בצעד אחד.

## נושאים שנסקרו
- הלבנה: הגדרה ומוטיבציה (תוחלת אפס, שונות משותפת יחידה מועדפת נומרית)
- הלבנת PCA: גזירה מ-$\mathbb{E}[Y]=0$, $\mathbb{E}[YY^\top]=I_d$; ייצוב נומרי עם $\epsilon$; פרשנות גאומטרית (מרכוז → סיבוב/דה-קורלציה → קנה-מידה)
- אמידת $\mu, \Sigma$ ממדגם i.i.d. סופי (אומדים חסרי-הטיה)
- הלבנת ZCA: אי-יחידות של $A$ עד כדי $R$ אוניטרית, הבחירה $R=U$, תכונת שימור-המבנה
- דוגמה — רגרסיה לינארית: מספר תנאי, קצב התכנסות לינארי של GD, השפעת ההלבנה

## בעיות פתורות וגזירות
**P1.** מצאו $A \in \mathbb{R}^{d,d}, b \in \mathbb{R}^d$ כך ש-$Y = AX + b$ מקיים $\mathbb{E}[Y]=0$ וכן $\mathbb{E}[YY^\top]=I_d$.
טכניקה: $0 = A\mu + b \Rightarrow Y = A(X-\mu)$; אזי $I_d = \mathbb{E}[A(X-\mu)(X-\mu)^\top A^\top] = A\Sigma A^\top$. הציבו את ה-EVD $\Sigma = UDU^\top$ (PSD) ובחרו $A_{\mathrm{PCA}} = D^{-1/2}U^\top$.

**P2.** הראו שמטריצת ההלבנה אינה יחידה וגזרו את ZCA.
טכניקה: אם $A\Sigma A^\top = I$ אזי $(RA)\Sigma(RA)^\top = I$ לכל $R$ אוניטרית. ZCA בוחרת $R = U$: $Y_{\mathrm{ZCA}} = UD^{-1/2}U^\top(X-\mu) = \Sigma^{-1/2}(X-\mu)$ — הלבנת PCA ואחריה ביטול הסיבוב המדה-קורל. ZCA ממזערת את $\mathbb{E}\|Y-(X-\mu)\|_2^2$ על פני כל $Y$ מולבן, כלומר נשארת הקרובה ביותר לנתונים המקוריים (הממורכזים).

**P3.** רגרסיה לינארית $f(w) = \tfrac{1}{2}\|X^\top w - y\|_2^2$, $X \in \mathbb{R}^{d,n}$, $n \ge d$, $\operatorname{rank}(XX^\top) = d$: כמתו את התכנסות GD ואת השפעת ההלבנה.
טכניקה: עם גודל צעד $\eta = 1/\lambda_{\max}$, $\|w_t - w^*\|_2^2 \le (1 - \tfrac{1}{K})^t \|w_0 - w^*\|_2^2$ כאשר $K = \lambda_{\max}(XX^\top)/\lambda_{\min}(XX^\top)$. נתונים מולבנים $\Rightarrow XX^\top = (n-1)I_d \Rightarrow K = 1 \Rightarrow$ התכנסות בצעד יחיד.

## נוסחאות ועובדות מפתח
- הגדרות: $\mathbb{E}[X] = \mu$, $\mathbb{E}[(X-\mu)(X-\mu)^\top] = \Sigma$; רוצים $Y = A(X-\mu)$ עם $A\Sigma A^\top = I$.
- הלבנת PCA: $\Sigma = UDU^\top$, $\;Y_{\mathrm{PCA}} = D^{-1/2}U^\top(X-\mu)$, $\;D^{-1/2} = \operatorname{diag}(1/\sqrt{D_{11}},\dots,1/\sqrt{D_{dd}})$.
- יציבות נומרית: $D^{-1/2} := \operatorname{diag}\!\big(1/\sqrt{D_{11}+\epsilon},\dots,1/\sqrt{D_{dd}+\epsilon}\big)$ עבור $\epsilon > 0$ קטן.
- אומדים חסרי-הטיה: $\hat\mu = \tfrac{1}{n}\sum_{i=1}^n X_i$, $\;\hat\Sigma = \tfrac{1}{n-1}\sum_{i=1}^n (X_i-\hat\mu)(X_i-\hat\mu)^\top$.
- הלבנת ZCA: $Y_{\mathrm{ZCA}} = UD^{-1/2}U^\top(X-\mu)$; זו ההלבנה הממזערת את $\mathbb{E}\|Y-(X-\mu)\|_2^2$.
- $X$ גאוסי: כל הלבנה מניבה קואורדינטות גאוסיות בלתי-תלויות; $X$ לא-גאוסי: בחירת ההלבנה משנה (סטטיסטיקות מסדר גבוה נבדלות).
- מספר תנאי: $K = \lambda_{\max}/\lambda_{\min} \ge 1$; GD עם $\eta = 1/\lambda_{\max}$: $\|w_t - w^*\|_2^2 \le (1-\tfrac1K)^t\|w_0-w^*\|_2^2$.

## נקודות רלוונטיות למבחן
- גזירת הלבנת ה-PCA המלאה (פתרו עבור $b$, ואז עבור $A$ דרך EVD) היא הוכחה קצרה ועצמאית — שאלת מבחן מהירה קלאסית.
- דעו *מדוע* $A$ אינה יחידה (הכפלה משמאל באוניטרית) ומה מייחד את ZCA: $\arg\min \mathbb{E}\|Y-(X-\mu)\|_2^2$, שימור מבנה; CNN-ים מניחים תלות גבוהה בין קואורדינטות שכנות, ולכן קלטי CNN חייבים הלבנה עם ZCA, לא PCA (נאמר גם ב-dl_standard_practices).
- סיפור המצוב הוא הגשר להרצאות האופטימיזציה: מצוב ירוד $K \gg 1 \Rightarrow (1-\tfrac1K) \to 1$ (אטי); מצוב טוב $K \approx 1 \Rightarrow$ מהיר; הלבנה $\Rightarrow K=1 \Rightarrow$ התכנסות בצעד אחד. דעו לשחזר את השרשרת הזו.
- זכרו את הרגולריזציה ב-$\epsilon$ של $D^{-1/2}$ (יציבות נומרית עם ערכים עצמיים קרובים-לאפס).
