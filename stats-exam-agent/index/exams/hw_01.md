**Solution sketch:**
*(סקיצות שנגזרו על ידי המורה — אין פתרונות רשמיים.)*

**a.** יחידת התצפית היא מדינה מתחרה בגמר ($n=26$ מדינות). נחקרים שני משתנים על כל מדינה: מספר ה"דוז פואה" שקיבלה בהצבעת הקהל, ומספר ה"דוז פואה" שקיבלה בהצבעת השופטים. שניהם משתנים **כמותיים בדידים** (ערכים שלמים אי-שליליים עם משמעות מספרית; ערכים חוזרים צפויים). בדיקת שפיות: סך הדוז פואה בהצבעת הקהל $13+5+4+2\cdot3+2\cdot2+6\cdot1=38$ = מספר המצביעים (37 מדינות + שאר העולם), ובהצבעת השופטים $8+6+5+4+2\cdot3+2+6\cdot1=37$ (אין שופטים ל"שאר העולם").

**b.** תרשים מקלות (התצוגה המתאימה לכמותי בדיד): ציר $x$ הוא מספר הדוז פואה בקנה מידה מספרי אמיתי — מקלות ב-0, 1, 2, 3, 4, 5 ו-13, עם רווח ריק בין 5 ל-13; גובה המקל = שכיחות. הגבהים: $0\mapsto13$, $1\mapsto6$, $2\mapsto2$, $3\mapsto2$, $4\mapsto1$, $5\mapsto1$, $13\mapsto1$ (13 המדינות שלא קיבלו אף דוז פואה הן $26-13=13$).

**c.** המדגם הממוין (קהל): שלושה-עשר אפסים, שישה 1, שניים 2, שניים 3, ואז 4, 5, 13. ממוצע: $\bar X=\frac{38}{26}\approx 1.46$. חציון: $n=26$ זוגי, $\frac{X_{(13)}+X_{(14)}}{2}=\frac{0+1}{2}=0.5$. שכיח: $0$ (שכיחות 13). טווח: $13-0=13$. רבעונים בנוסחת הקורס עם $n+1=27$: עבור $Q_1$: $27\cdot0.25=6.75$, כלומר בין $X_{(6)}=0$ ל-$X_{(7)}=0$, ולכן $Q_1=0$; עבור $Q_3$: $27\cdot0.75=20.25$, בין $X_{(20)}=2$ ל-$X_{(21)}=2$, ולכן $Q_3=2$; $IQR=2-0=2$. סטיית תקן: $\sum x_i^2=169+25+16+18+8+6=242$, ולכן

$$S^2=\frac{242-26\cdot(38/26)^2}{25}=\frac{242-55.54}{25}\approx 7.46$$

ו-$S\approx 2.73$.

**d.**

**שלב 1 — בחירת הכלי ולמה:** תרשימי קופסה זה לצד זה, ולא היסטוגרמות נפרדות — כי ההשוואה כאן היא של מרכז, פיזור וחריגים, ותרשים הקופסה מציג את שלושתם על אותו סרגל ומאפשר קריאה ישירה של הגדרות.

**שלב 2 — חישוב:** קהל: $Q_1=0$, חציון $0.5$, $Q_3=2$, גדר עליונה $Q_3+1.5\cdot IQR=5$ — השפם העליון מגיע עד 5 (אסטוניה), ו-**13 (ישראל) תצפית חריגה** קיצונית. שופטים: מדגם ממוין עם 13 אפסים, שישה 1, ואז $2,3,3,4,5,6,8$; חציון $0.5$, $Q_1=0$,

$$Q_3=0.75\cdot X_{(20)}+0.25\cdot X_{(21)}=0.75\cdot2+0.25\cdot3=2.25$$

גדר עליונה $2.25+3.375=5.625$ — השפם עד 5 (צרפת), ו-**6 ו-8 (איטליה ואוסטריה) תצפיות חריגות**.

**שלב 3 — פרשנות:** צורה: שתי ההתפלגויות חד-דבשתיות (שיא ב-0), א-סימטריות מובהקות עם **זנב ימני** ארוך — הקופסה צמודה לאפס והחציון בתחתיתה. דומה: אותו שכיח (0), אותו חציון (0.5), ממוצעים כמעט זהים ($1.46$ מול $1.42$), רוב המדינות בלי אף דוז פואה. שונה: אצל הקהל הקולות מרוכזים בחריג אחד קיצוני מאוד (ישראל, 13), בעוד אצל השופטים הזנב מפוזר בין כמה מדינות (8, 6, 5, 4) עם חריגים מתונים יותר; לכן פיזור הקהל (טווח 13) גדול מזה של השופטים (טווח 8) למרות שהסכומים כמעט שווים.

**💡 טריק.** במשתנה בדיד עם שכיחויות, עבדו ישר על המדגם הממוין לפי שכיחויות מצטברות (13 אפסים ⇒ $X_{(1)},\dots,X_{(13)}=0$), וזכרו את נוסחת הקורס לשברון: $k=\lfloor p(n+1)\rfloor$, $r=\{p(n+1)\}$, שברון $=(1-r)X_{(k)}+rX_{(k+1)}$.

**⚠️ שים לב.** אל תשכחו את קבוצת האפסים — "יתר המדינות" הן $26-13=13$ תצפיות של 0 שבלעדיהן כל המדדים שגויים; ותרשים מקלות (לא תרשים עמודות) הוא התצוגה הנכונה לכמותי בדיד, עם ציר $x$ בקנה מידה אמיתי שמשאיר רווח בין 5 ל-13.

## Q2 (10 pts) — מספר המילים בשירי רחל: היסטוגרמה ורגישות הממוצע, החציון, הטווח, הסדרון וסטיית התקן לשינויים במדגם
**Topics:** היסטוגרמה, בחירת רוחב מחלקות, ממוצע, חציון, טווח, סדרון, סטיית תקן, רגישות תמציות | **Pillar:** Descriptive | **Difficulty:** 2
**Maps to:** week_01
**Hint:**
- a) בחרו מספר מחלקות בסדר גודל של שורש מספר התצפיות, וודאו שגובה העמודה מבטא צפיפות; בדקו מה קורה לצורה ברוחב צר מדי וברוחב רחב מדי.
- b) עקבו אחרי מיקום שני הערכים החדשים ביחס לחציון ולממוצע, וזכרו שגם גודל המדגם גדל — מה זה עושה לסדרון שהיה עד כה המקסימום?
- c) שימו לב שהסכום אינו משתנה ולכן הממוצע קבוע; שאלו מה קורה לסכום ריבועי הסטיות כשתצפיות מוחלפות בערכים ששווים בדיוק לממוצע.
**Statement (English translation):**
חוקרת שירה עורכת מחקר על יצירתה של רחל המשוררת. במסגרת המחקר נבדק מספר המילים במדגם אקראי של 13 שירים, והתקבלו הנתונים הבאים:

$$51,\ 36,\ 53,\ 39,\ 39,\ 41,\ 43,\ 50,\ 20,\ 34,\ 46,\ 30,\ 38$$

**a.** הציגו את הנתונים באמצעות היסטוגרמה. בחרו רוחב מחלקות (bins) הולם.

**b.** ללא חישוב מפורש, תארו כיצד ישתנו הממוצע, החציון, הטווח, והסדרון ה-13 אם יתווספו למדגם שני שירים נוספים: "חג" (36 מילים) ו"זמר נוגה" (59 מילים).

**c.** ללא חישוב מפורש, תארו כיצד ישתנו החציון וסטיית התקן אם תגלה החוקרת כי במקום 30 ו-50, היתה אמורה להקליד פעמיים 40.

**Solution sketch:**
*(סקיצות שנגזרו על ידי המורה — אין פתרונות רשמיים.)*

**a.** המדגם הממוין: $20, 30, 34, 36, 38, 39, 39, 41, 43, 46, 50, 51, 53$. עבור $n=13$ מתאימות בערך $\sqrt{13}\approx 3{-}4$ מחלקות, למשל רוחב 10 על $[20,60)$: המחלקות $[20,30), [30,40), [40,50), [50,60)$ עם שכיחויות $1, 6, 3, 3$ וצפיפויות $0.1, 0.6, 0.3, 0.3$ (גובה = שכיחות חלקי רוחב). מתקבלת התפלגות חד-דבשתית עם שיא בשנות ה-30 וזנב שמאלי קל (התצפית 20). רוחב צר מדי (למשל 2) ייתן היסטוגרמה "מסורקת" ורועשת; רוחב רחב מדי (למשל 20) ימחק את הצורה.

**b.**

**שלב 1 — בחירת הכלי ולמה:** עוקבים אחרי מיקום שני הערכים החדשים ביחס לתמציות הקיימות במקום לחשב הכול מחדש — כי השאלה מבקשת כיוון שינוי בלבד, וכל תמצית מגיבה אחרת לתוספת בקצה ולגידול בגודל המדגם.

**שלב 2 — חישוב:** הנתונים הנוכחיים: ממוצע $\frac{520}{13}=40$, חציון $X_{(7)}=39$, טווח $53-20=33$, סדרון 13 $=X_{(13)}=53$ (המקסימום).

**שלב 3 — פרשנות:** לאחר ההוספה: **הממוצע יעלה** — ממוצע שני השירים החדשים הוא $\frac{36+59}{2}=47.5>40$, ולכן הממוצע החדש גדול מ-40 (ליתר דיוק עולה ל-41). **החציון לא ישתנה** — נוסף ערך אחד מתחת לחציון (36) ואחד מעליו (59), כך שהאיבר האמצעי ($X_{(8)}$ מבין 15) נשאר 39. **הטווח יגדל** — המינימום נשאר 20 אך המקסימום עולה ל-59, ולכן הטווח גדל מ-33 ל-39. **הסדרון ה-13 יקטן**: הוא כבר אינו המקסימום; הוספת 36 (הקטן מ-$X_{(12)}=51$) דוחפת את 51 למקום ה-13, והוספת 59 (הגדול מ-51) אינה משנה זאת — הסדרון ה-13 יורד מ-53 ל-51.

**c.** הסכום אינו משתנה ($30+50=40+40$), ולכן הממוצע נשאר 40. **החציון יעלה מעט**: הוסר ערך אחד מתחת לחציון (30) ונוספו שני ערכים (40, 40) מעל החציון הישן 39, כך שהאיבר האמצעי זז צעד אחד למעלה — מ-39 ל-40 (המדגם המתוקן הממוין: $20,34,36,38,39,39,40,40,41,\dots$, ו-$X_{(7)}=40$). **סטיית התקן תקטן ממש**: הממוצע נשאר 40, ושתי תצפיות שסטו ממנו ($30$ ו-$50$, תרומה $(30-40)^2+(50-40)^2=200$ לסכום ריבועי הסטיות) הוחלפו בערכים השווים בדיוק לממוצע (תרומה 0); כל שאר הסטיות ללא שינוי, ולכן $S$ קטנה.

**💡 טריק.** כדי לנתח שינוי במדגם בלי לחשב מחדש, עקבו אחרי מיקום הערכים ביחס לחציון ולממוצע — הוספת זוג ערכים משני צידי החציון משאירה אותו במקומו, והחלפת ערכים בערכים קרובים יותר לממוצע (בלי לשנות את הסכום) מקטינה בהכרח את סטיית התקן.

**⚠️ שים לב.** "ללא חישוב מפורש" אין פירושו תשובה מעורפלת — נדרש כיוון השינוי עם נימוק (למשל: ממוצע המתווספים 47.5 גדול מ-40 ולכן הממוצע עולה); ושימו לב שהסדרון ה-13 מפסיק להיות המקסימום כשהמדגם גדל ל-15, ולכן דווקא *קטן* אף ששני ערכים נוספו.

## Q3 (10 pts) — סדרונים תחת טרנספורמציות לינאריות ומונוטוניות, וטענות נכון/לא נכון על רבעונים ותרשים קופסה

- b) פונקציה עולה משמרת את יחס הסדר בין כל שתי תצפיות; מה זה אומר על הדירוג של המדגם?
- c) פונקציה יורדת הופכת את יחס הסדר — איזה סדרון של המקור הופך לסדרון הראשון של התוצאה?

**Statement (English translation):**
ב-3 הסעיפים הבאים, בטאו את הסדרון ה-$i$ של $Y$ (כלומר, $Y_{(i)}$) באמצעות הסדרונים של $X$ (כלומר, $X_{(1)},\dots,X_{(n)}$), כאשר:

**a.** $Y$ מחושב באופן לינארי ביחס ל-$X$, כלומר $Y_i = aX_i + b$ עבור $a,b\in\mathbb{R}$ קבועים כלשהם.

**b.** $Y$ מחושב ביחס ל-$X$ באופן הבא: $Y = g(X)$ כאשר $g:\mathbb{R}\to\mathbb{R}$ פונקציה מונוטונית עולה.

**c.** $Y$ מחושב ביחס ל-$X$ באופן הבא: $Y = g(X)$ כאשר $g:\mathbb{R}\to\mathbb{R}$ פונקציה מונוטונית יורדת.

בשני הסעיפים הבאים, קבעו האם הטענה נכונה/לא נכונה, ונמקו:

**d.** בהנתן מדגם מקרי $X_1,\dots,X_n$, אם מתקיים כי הסדרון הראשון שווה לרבעון הראשון, וגם מתקיים כי $X_{(n)} - X_{(1)} \le 2.5\cdot IQR$, אזי בתרשים הקופסה לא יהיו תצפיות חריגות.

**e.** אם החציון שווה לרבעון העליון, אזי ההתפלגות היא א-סימטרית עם זנב שמאלי.

**Solution sketch:**
*(סקיצות שנגזרו על ידי המורה — אין פתרונות רשמיים.)*

**a.** **הכרעה ונימוק:** יש לפצל לפי סימן $a$. אם $a\ge 0$ ההעתקה שומרת סדר: $Y_{(i)} = aX_{(i)} + b$. אם $a<0$ ההעתקה הופכת סדר (הגדול ביותר הופך לקטן ביותר): $Y_{(i)} = aX_{(n-i+1)} + b$. (עבור $a=0$ שתי הנוסחאות מסכימות: כל הסדרונים שווים $b$.)

**b.** **הכרעה ונימוק:** פונקציה מונוטונית עולה שומרת על יחס הסדר בין כל שתי תצפיות ($x\le x' \Rightarrow g(x)\le g(x')$), ולכן דירוג התצפיות אינו משתנה: $Y_{(i)} = g\!\left(X_{(i)}\right)$.

**c.** **הכרעה ונימוק:** פונקציה מונוטונית יורדת הופכת את הסדר: התצפית הקטנה ביותר ב-$X$ נותנת את הגדולה ביותר ב-$Y$, ולכן $Y_{(i)} = g\!\left(X_{(n-i+1)}\right)$.

**d.** **נכון.**

**שלב 1 — חישוב:** כלל החריגים: תצפית חריגה אם היא מחוץ ל-$[Q_1 - 1.5\cdot IQR,\ Q_3 + 1.5\cdot IQR]$. למטה: $X_{(1)} = Q_1 \ge Q_1 - 1.5\cdot IQR$, ולכן אין חריגים תחתונים. למעלה: מהנתון,

$$
\begin{aligned}
X_{(n)} &\le X_{(1)} + 2.5\cdot IQR = Q_1 + 2.5\cdot IQR \\
&= (Q_3 - IQR) + 2.5\cdot IQR = Q_3 + 1.5\cdot IQR
\end{aligned}
$$

ולכן גם אין חריגים עליונים.

**שלב 2 — הכרעה:** כל התצפיות בתוך הגדרות — אין תצפיות חריגות.

**e.** **לא נכון.**

**שלב 1 — חישוב:** חציון $=Q_3$ אמנם מרמז בדרך כלל על דחיסות בחלק העליון (זנב שמאלי), אך אין זה הכרחי — ההתפלגות יכולה להיות סימטרית לחלוטין. דוגמה נגדית: המדגם $1, 5, 5, 5, 5, 5, 5, 9$ ($n=8$, $n+1=9$). חציון: $4.5 \Rightarrow$ בין $X_{(4)}=5$ ל-$X_{(5)}=5$, כלומר 5; $Q_3$: $9\cdot0.75=6.75 \Rightarrow$ בין $X_{(6)}=5$ ל-$X_{(7)}=5$, כלומר 5.

**שלב 2 — הכרעה:** אכן חציון $=Q_3=5$, אך המדגם סימטרי לגמרי סביב 5 (וגם $Q_1=5$). לכן שוויון חציון ורבעון עליון אינו גורר א-סימטריה.

**💡 טריק.** טרנספורמציה שומרת-סדר משמרת סדרונים ($Y_{(i)}=g(X_{(i)})$) והופכת-סדר משקפת אותם ($Y_{(i)}=g(X_{(n-i+1)})$); וכדי להפריך טענות "צורת התפלגות", חפשו דוגמה נגדית עם גוש ערכים זהים במרכז שמאפס את ה-$IQR$.

**⚠️ שים לב.** בסעיף הלינארי $a$ יכול להיות שלילי — תשובה $Y_{(i)}=aX_{(i)}+b$ בלי פיצול מקרים שגויה; ובסעיף ה' אל תסיקו א-סימטריה משוויון רבעונים — כשרבעונים מתלכדים ייתכן ש-$Q_1=\text{median}=Q_3$ בהתפלגות סימטרית.

## Q4 (10 pts) — אילו תמציות הן תמציות למיקום ואילו תמציות לפיזור
**Topics:** תמצית למרכז, תמצית לפיזור, תכונות אי-שינוי, ממוצע ממושקל, ממוצע קטום, רבעונים, טווח, שונות מדגמית | **Pillar:** Descriptive | **Difficulty:** 3
**Maps to:** week_01
**Hint:**
- a) בדקו את שתי תכונות תמצית המיקום על הממוצע הממושקל, ושימו לב שדרושה הנחה על סכום המשקולות.
- b) עבור כפל בקבוע שלילי בדקו מה קורה לזוג הרבעונים — האם הם נשארים במקומם או מתחלפים ביניהם?
- c) שאלו האם קבוצת התצפיות שנשארת אחרי הקיטום היא אותה קבוצה גם אחרי הזזה וגם אחרי כפל בקבוע שלילי.
- d) בדקו את שתי הדרישות בנפרד, וכן ודאו שהתוצאה אינה יכולה לצאת שלילית.
- e) השוו את קצב הגידול של הגודל תחת כפל בקבוע לקצב הגידול שתמצית פיזור חייבת לקיים.
**Statement (English translation):**
ביחס למדגם מקרי $X_1,\dots,X_n$, בדקו האם התמציות הנתונות בסעיפים א'–ג' מהוות תמציות למיקום, והאם התמציות הנתונות בסעיפים ד'–ה' מהוות תמציות לפיזור:

**a.** ממוצע ממושקל של $m$ תמציות מיקום:

$$T(X_1,\dots,X_n) = \frac{\sum_{i=1}^{m} w_i\, T_i(X_1,\dots,X_n)}{\sum_{i=1}^{m} w_i}, \qquad \text{כאשר } w_i \ge 0 \ \ \forall i=1,\dots,m.$$

**b.** אמצע הטווח בין הרבעון העליון לרבעון התחתון.

**c.** הממוצע הקטום, המחושב על סמך $n - \lfloor n\alpha\rfloor$ התצפיות המרכזיות, עבור $\alpha\in[0,1)$.

**d.** הטווח (Range) פחות הטווח הבין-רבעוני (IQR).

**e.** השונות המדגמית.

**Solution sketch:**
*(סקיצות שנגזרו על ידי המורה — אין פתרונות רשמיים. תזכורת להגדרות הקורס: תמצית למרכז מקיימת $T(\underline X + a) = T(\underline X) + a$ לכל $a\in\mathbb{R}$ ו-$T(c\underline X) = c\,T(\underline X)$ לכל $c\in\mathbb{R}$; תמצית לפיזור מקיימת $T(\underline X + a) = T(\underline X)$ ו-$T(c\underline X) = |c|\,T(\underline X)$ לכל $a,c\in\mathbb{R}$.)*

**a.** **כן, תמצית למיקום** (בהנחה ש-$\sum w_i > 0$).

**שלב 1 — חישוב:** כל $T_i$ תמצית מיקום, ולכן מלינאריות:

$$T(\underline X + a) = \frac{\sum w_i (T_i(\underline X)+a)}{\sum w_i} = T(\underline X) + a$$

וכן

$$T(c\underline X) = \frac{\sum w_i\, c\,T_i(\underline X)}{\sum w_i} = c\,T(\underline X)$$

**שלב 2 — הכרעה:** שתי התכונות מתקיימות לכל $a,c\in\mathbb{R}$.

**b.** **כן, תמצית למיקום.**

**שלב 1 — חישוב:** נסמן $T = \frac{Q_1 + Q_3}{2}$. הזזה: כל שברון מוזז — $Q_j(\underline X + a) = Q_j(\underline X) + a$, ולכן $T(\underline X+a)=T(\underline X)+a$. כפל: עבור $c\ge0$ השברונים נכפלים ב-$c$; עבור $c<0$ הרבעונים *מתחלפים* — $Q_1(c\underline X) = c\,Q_3(\underline X)$ ו-$Q_3(c\underline X) = c\,Q_1(\underline X)$ (נוסחת השברון עם $p(n+1)$ סימטרית תחת $p\mapsto 1-p$ והיפוך סדר) — אך הממוצע שלהם בכל זאת מקיים

$$T(c\underline X) = \frac{cQ_3 + cQ_1}{2} = c\,T(\underline X)$$

**שלב 2 — הכרעה:** שתי התכונות מתקיימות.

**c.** **כן, תמצית למיקום.**

**שלב 1 — חישוב:** הקיטום סימטרי: מסירים אותו מספר תצפיות מכל זנב ונשארים עם קבוצת האינדקסים המרכזית $\{l+1,\dots,n-l\}$ של המדגם הממוין. הזזה וכפל ב-$c>0$ אינם משנים את הדירוג, ולכן אותן תצפיות בדיוק נשארות, והממוצע שלהן מקיים $T(\underline X+a)=T(\underline X)+a$, $T(c\underline X)=cT(\underline X)$.

**שלב 2 — הכרעה:** עבור $c<0$ הסדר מתהפך, אך קבוצת התצפיות המרכזיות סימטרית ולכן עוברת לעצמה — שוב $T(c\underline X)=c\,T(\underline X)$.

**d.** **כן, תמצית לפיזור.**

**שלב 1 — חישוב:** הזזה: גם הטווח וגם ה-IQR אינם משתנים תחת $\underline X + a$, ולכן ההפרש אינו משתנה. כפל: $Range(c\underline X) = |c|\cdot Range(\underline X)$ וכן $IQR(c\underline X) = |c|\cdot IQR(\underline X)$ (עבור $c<0$ המינימום/מקסימום והרבעונים מתחלפים בזוגות), ולכן $T(c\underline X) = |c|\,T(\underline X)$.

**שלב 2 — הכרעה:** בנוסף $T\ge 0$ תמיד, שכן $[Q_1,Q_3]\subseteq[X_{(1)},X_{(n)}]$ גורר $IQR \le Range$ — עקבי עם הדרישה שתמצית לפיזור אי-שלילית.

**e.** **לא, השונות המדגמית אינה תמצית לפיזור.**

**שלב 1 — חישוב:** היא אמנם חסינה להזזה ($S^2(\underline X+a)=S^2(\underline X)$), אך תחת כפל:

$$S^2(c\underline X) = c^2\,S^2(\underline X) \ne |c|\,S^2(\underline X)$$

באופן כללי — למשל $c=2$ נותן פי 4 במקום פי 2.

**שלב 2 — הכרעה:** התכונה השנייה נכשלת; דווקא סטיית התקן $S$ (השורש) היא תמצית לפיזור.

**💡 טריק.** בדקו כל תמצית מול שתי תכונות האי-שינוי בלבד — הזזה וכפל בקבוע *לכל* $c\in\mathbb{R}$ — וזכרו שתחת $c<0$ סדרונים ושברונים מתחלפים בזוגות סימטריים ($X_{(i)}\leftrightarrow X_{(n-i+1)}$, $Q_1\leftrightarrow Q_3$), מה שמציל תמציות סימטריות כמו אמצע הרבעונים והממוצע הקטום.

**⚠️ שים לב.** אל תסתפקו בבדיקת $c>0$ — ההגדרה דורשת כל $c\in\mathbb{R}$; והמלכודת הקלאסית היא השונות: היא מתרחבת ב-$c^2$ ולא ב-$|c|$, ולכן איננה תמצית לפיזור אף שסטיית התקן כן.

## Q5 (10 pts) — (לא להגשה) מימוש תמציות ב-R ונוסחת השברון המדגמי
**Topics:** תכנות ב-R, שברון מדגמי, אינטרפולציה לינארית, ממוצע קטום, טווח, טווח בין-רבעוני | **Pillar:** Descriptive | **Difficulty:** 2
**Maps to:** week_01
**Hint:** ממשו קודם את נוסחת השברון של הקורס — מיון, חלק שלם וחלק שברי של המכפלה, ואז אינטרפולציה בין שני סדרונים סמוכים — ובנו את שאר התמציות מעליה; בהשוואה לפונקציה המובנית ב-R בחרו את סוג השברון שתואם למוסכמת הקורס.
**Statement (English translation):**
**לא להגשה — תרגול כתיבת קוד.** כתבו פונקציה ב-R (ללא שימוש בפונקציות מובנות כגון mean, quantile וכדומה) אשר מקבלת כקלט וקטור של מדגם מקרי בגודל $n$, ומחזירה את ערך התמצית עבור כל אחת מהתמציות המופיעות בסעיפים ב', ג', ד' בשאלה 4. בדקו את תשובתכם בהשוואה לערכים המתקבלים משימוש בפונקציות המובנות המתאימות. למשל, בסעיף ב' החישוב נשען על אחוזונים. כדי לחשב אחוזון $X_p$, ממשו בקוד בעצמכן את הנוסחה

$$X_p = (1-r)X_{(k)} + rX_{(k+1)}\ , \qquad \text{כאשר: } k = \lfloor (n+1)p\rfloor,\ \ r = \{(n+1)p\}$$

כדי לבדוק את פתרונכן בסעיף ב', השתמשו בנוסחאות המובנות לטווח ולטווח בין-רבעוני.

**Solution sketch:**
*(סקיצה שנגזרה על ידי המורה — אין פתרונות רשמיים. סעיף תרגול, לא להגשה.)*

**שלב 1 — חישוב:**

**שברון מדגמי.** הלב הוא מימוש נוסחת הקורס: ממיינים, מחשבים $k=\lfloor(n+1)p\rfloor$ ו-$r=(n+1)p-k$, ומחזירים אינטרפולציה לינארית בין שני הסדרונים הסמוכים.

```r
my_quantile <- function(x, p) {
  xs <- sort(x); n <- length(x)
  k <- floor((n + 1) * p); r <- (n + 1) * p - k
  if (k == 0) return(xs[1])        # p קטן מאוד
  if (k >= n) return(xs[n])        # p גדול מאוד
  (1 - r) * xs[k] + r * xs[k + 1]
}

# 4ב: אמצע הטווח בין הרבעונים
midhinge <- function(x) (my_quantile(x, 0.25) + my_quantile(x, 0.75)) / 2

# 4ג: ממוצע קטום על n - floor(n*alpha) התצפיות המרכזיות
my_trimmed_mean <- function(x, alpha) {
  xs <- sort(x); n <- length(x)
  m <- floor(n * alpha)            # כמה מסירים בסך הכול
  l <- floor(m / 2); u <- m - l    # חצי מכל זנב
  core <- xs[(l + 1):(n - u)]
  sum(core) / length(core)
}

# 4ד: טווח פחות טווח בין-רבעוני
range_minus_iqr <- function(x) {
  xs <- sort(x); n <- length(x)
  (xs[n] - xs[1]) - (my_quantile(x, 0.75) - my_quantile(x, 0.25))
}
```

**שלב 2 — פרשנות:**

**בדיקה מול המובנות.** למשל על נתוני שאלה 2: `x <- c(51,36,53,39,39,41,43,50,20,34,46,30,38)`. משווים `my_quantile(x, .25)` ו-`my_quantile(x, .75)` אל `quantile(x, c(.25,.75), type = 6)` (type 6 ב-R הוא בדיוק מוסכמת $p(n+1)$ של הקורס; ברירת המחדל type 7 עשויה לתת ערכים שונים במקצת), את הטווח אל `diff(range(x))`, ואת `range_minus_iqr` אל `diff(range(x)) - IQR(x, type = 6)`. עבור המדגם הזה:

$$Q_1 = X_{(3.5)} = \frac{34+36}{2} = 35$$

$$Q_3 = X_{(10.5)} = \frac{46+50}{2} = 48$$

ולכן midhinge $= 41.5$, ו-Range $-$ IQR $= 33 - 13 = 20$.

**💡 טריק.** מימוש עצמי של נוסחת השברון $k=\lfloor(n+1)p\rfloor,\ r=\{(n+1)p\}$ הוא הדרך לוודא שאתם שולטים במוסכמת הקורס — והיא שקולה ל-`quantile(..., type = 6)` ב-R.

**⚠️ שים לב.** ברירת המחדל של `quantile` ב-R (type 7, מבוסס $p(n-1)+1$) שונה מנוסחת הקורס ותיתן רבעונים אחרים במדגמים קטנים; וטפלו במקרי הקצה $k=0$ או $k=n$ שבהם אין $X_{(k+1)}$ לאינטרפולציה.
