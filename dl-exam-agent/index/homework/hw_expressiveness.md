## Problems
### Part 1: Fully Connected ReLU Networks with 1D Input

**P1.1 (12 pts).** Prove the class proposition: a shallow (one-hidden-layer) ReLU network of width $B \ge 2$ can realize any piecewise linear mapping $\mathbb{R}\to\mathbb{R}$ with $\le B$ pieces; conversely, any mapping realized by such a network is piecewise linear with $\le B+1$ pieces. Explain why $B \ge 2$ is needed.
Key ideas:
- Constructive direction: build each slope change with a ReLU unit $c_i\max(0, x - b_i)$ placed at the breakpoints; two units are needed to set the initial slope/affine part (hence $B \ge 2$).
- Converse: each ReLU contributes at most one breakpoint, so $B$ units give $\le B$ breakpoints $= \le B+1$ linear pieces.

**P1.2 (15 pts).** Depth separation via the "sawteeth" function $g^{\circ L-1}$ (the $(L-1)$-fold composition of the triangle map): show it is inapproximable by shallow ReLU nets $\mathcal{H}_B$ unless $B$ is exponential in $L$. (A proof is in the class notes; the task is to rewrite it.)
(a) (6 pts) With $S_> := \{x : g^{\circ L-1}(x) > \tfrac12\} = \bigcup_{i=1}^{2^{L-2}}\big(2^{-L+2}(i-1) + \tfrac14 2^{-L+2},\, 2^{-L+2}(i-1) + \tfrac34 2^{-L+2}\big)$ and $S_< := \{x \in [0,1] : g^{\circ L-1}(x) < \tfrac12\}$ (the complementary $2^{L-2}-1$ interior intervals plus the two boundary pieces $[0, \tfrac14 2^{-L+2})$, $(1 - \tfrac14 2^{-L+2}, 1]$): a function $f$ "misses" an interval of $S_>$ if $f \le \tfrac12$ on it (resp. $f \ge \tfrac12$ for $S_<$). Prove that a piecewise linear mapping with $\le B+1$ pieces can avoid missing at most $\big\lceil \tfrac12(2^{L-1}+1) + \tfrac12(B+1) \big\rceil$ of the intervals of $S_>$ and $S_<$.
(b) (6 pts) Prove $d(g^{\circ L-1}, h) \ge \tfrac18 - B\cdot2^{-L-2} - 3\cdot2^{-L-1}$ for every $h \in \mathcal{H}_B$, where $d(f_1,f_2)=\int_0^1|f_1-f_2|$. Hint: if $f$ misses an interval of $S_>$ or $S_<$, then $\int |f - g^{\circ L-1}|$ over that interval is at least $[\text{interval length}]\cdot\tfrac12\cdot\tfrac12$.
(c) (3 pts) Conclude: approximating $g^{\circ L-1}$ within $\epsilon$ forces $B > 2^{L+2}\big(\tfrac18 - \epsilon\big) - 6$.
Key ideas:
- $S_>$/$S_<$ intervals alternate ($2^{L-1}+1$ of them in total); crossing from "not missing" one interval to "not missing" the adjacent one requires the piecewise linear $h$ to cross the level $\tfrac12$, consuming a linear piece — a counting/pigeonhole argument.
- Each missed interval contributes $\ge \text{length}\cdot\tfrac14$ to the $L^1$ error; summing over the many missed intervals gives the lower bound.
- Rearranging error $\le \epsilon$ yields the exponential width lower bound $B = \Omega(2^L)$ — the depth-separation punchline.

**P1.3 (10 pts).** Modify the universality and expressive-efficiency analyses from class so they hold for leaky ReLU $\sigma(z) = \max\{az, z\}$, $a \in (0,1)$, instead of ReLU.
Key ideas:
- Express a ReLU (or a hard breakpoint) as a linear combination of leaky ReLUs, e.g. $\max(0,z) = \frac{1}{1-a}\big(\sigma(z) - a\,z\big)$ with $z = \sigma(z) - \sigma(-z)$ tricks; breakpoint counting is unchanged since leaky ReLU still has exactly one kink.
- Universality: reconstruct the hat/indicator building blocks with leaky ReLUs; efficiency: the sawteeth lower-bound argument only uses piecewise linearity, so it transfers verbatim.

**P1.4 (Bonus 8 pts).** Prove shallow and deep networks are $\mathcal{F}$-universal for $\mathcal{F} =$ Riemann-integrable functions on $[0,1]$ w.r.t. $d(f_1,f_2) := \int_0^1 |f_1(x)-f_2(x)|\,dx$ (class proved it for continuous functions).
Key ideas:
- Riemann integrability gives step-function (Darboux sum) approximation in $L^1$; approximate step functions by piecewise linear functions with steep ramps of negligible measure.
- Chain the triangle inequality: net $\to$ piecewise linear $\to$ step function $\to$ $f$.

### Part 2: Convolutional Arithmetic Circuits

**P2.1 (5 pts).** Prove the class proposition: the tensor generated by the deep convolutional arithmetic circuit satisfies the Hierarchical Tucker recursion
$$\phi^{1,j,\gamma} = \sum_{\alpha=1}^{r_0} a^{1,j,\gamma}_\alpha\, \underline{a}^{0,2j-1,\alpha} \otimes \underline{a}^{0,2j,\alpha},\quad \phi^{l,j,\gamma} = \sum_{\alpha=1}^{r_{l-1}} a^{l,j,\gamma}_\alpha\, \phi^{l-1,2j-1,\alpha} \otimes \phi^{l-1,2j,\alpha},\quad \mathcal{A} = \sum_{\alpha=1}^{r_{L-1}} a^L_\alpha\, \phi^{L-1,1,\alpha} \otimes \phi^{L-1,2,\alpha}$$
($\otimes$ = outer product; $\phi^{l,j,\gamma}$ has order $2^l$; rewrite the class-notes proof in your own words).
Key ideas:
- Induction over layers: $1\times1$ conv = linear combination over channels ($\sum_\alpha a_\alpha \cdot$), product pooling of size 2 = outer product of the two children subtrees.
- Establishes the equivalence: deep conv arithmetic circuit $\Leftrightarrow$ Hierarchical Tucker tensor decomposition.

**P2.2 (10 pts).** Prove the class lemma "matricization of outer product = Kronecker product of matricizations": for tensors $T, \bar T$ of orders $n, \bar n$ and $I \subset [n+\bar n]$,
$$[\![T \otimes \bar T]\!]_I = [\![T]\!]_{I\cap[n]} \odot [\![\bar T]\!]_{(I-n)\cap[\bar n]},$$
where $\odot$ is the Kronecker product and $I - n$ subtracts $n$ from each element of $I$.
Key ideas:
- Compare entries: index a matricization row/column by mixed-radix encodings of the mode indices in $I$ / $I^c$; the outer product's entry factorizes as $T_{d_1..d_n}\bar T_{d_{n+1}..d_{n+\bar n}}$, exactly matching the Kronecker block structure.
- This lemma is the engine for rank-based lower bounds: $\operatorname{rank}(A \odot B) = \operatorname{rank}(A)\operatorname{rank}(B)$.

**P2.3 (9 pts).** Redo the expressive-efficiency analysis for a deep network with $\log_4 N$ hidden layers and pooling windows of size 4 ($N$ a power of 4), instead of $\log_2 N$ layers with size-2 pooling.
Key ideas:
- Pooling window 4 $\Rightarrow$ each node takes the outer product of 4 children; the HT recursion becomes 4-ary.
- Track how matricization ranks multiply across 4 children per level; the maximal-rank / exponential separation result carries over with adjusted exponents.

**P2.4 (10 pts).** For the "quadrant" partition $I_{\text{quad}} = \{1,\dots,\tfrac{N}{4}\} \cup \{\tfrac{N}{2}+1,\dots,\tfrac34 N\}$, $I^C_{\text{quad}} = \{\tfrac{N}{4}+1,\dots,\tfrac{N}{2}\} \cup \{\tfrac34 N + 1,\dots,N\}$: prove the separation rank of a function realized by the deep network (with $L = \log_2 N$ hidden layers) is at most $r_{L-1}\cdot r_{L-2}^2$, where $r_l$ is the width of hidden layer $l$.
Key ideas:
- The quadrant partition splits each of the two top-level subtrees (and both children of each) evenly; expand the top of the HT decomposition down two levels.
- $\mathcal{A} = \sum_{\alpha}^{r_{L-1}} a_\alpha^L\, \phi^{L-1,1,\alpha}\otimes\phi^{L-1,2,\alpha}$ with each $\phi^{L-1,j,\alpha} = \sum_{\beta}^{r_{L-2}}(\cdot)$: counting the summations that separate $I_{\text{quad}}$ from its complement gives $r_{L-1}\, r_{L-2}^2$ separable terms — separation rank is sub-additive over sums of separable products.
- Moral: deep networks are only exponentially expressive w.r.t. partitions misaligned with their pooling tree in a controlled way; interleaved vs. quadrant partitions matter.

### Part 3: Optimization in Deep Learning Is Non-Convex

**P3.1 (7 pts).** Prove the class proposition: for a depth-$N \ge 2$ FFFC network $y = W_N\sigma(W_{N-1}\cdots\sigma(W_1x)\cdots)$ and a continuously differentiable loss $L(W_1,\dots,W_N)$ depending on weights only through the network's input–output map, if the global minimum is not attained at $(W_1,\dots,W_N) = (0,\dots,0)$ and $\sigma \in C^1$ with $\sigma(0)=0$, then $L(\cdot)$ is non-convex.
Key ideas:
- At the all-zeros point the network output is $0$ regardless of any single layer's weights, so $\nabla L(0,\dots,0) = 0$ (each partial derivative vanishes because perturbing one layer alone keeps the map zero).
- A convex function with zero gradient at a point attains its global minimum there — contradicting the assumption; hence $L$ is non-convex.

### Part 4: Landscape Approach

**P4.1 (8 pts).** Extend the class GD-to-stationarity result to SGD. Let $f \in C^2$ be $\beta$-smooth with global min $f^*$; run $w_{t+1} = w_t - \eta_t(\nabla f(w_t) + \xi_t)$ with zero-mean noise, $\mathbb{E}[\|\xi_t\|^2] = \sigma^2$. With $\eta_t = \tfrac1\beta$, derive an upper bound on $T$ ensuring $\min_{t\in[T]}\mathbb{E}[\|\nabla f(w_t)\|] \le \epsilon + \sigma$.
Key ideas:
- Descent lemma with noise: $\mathbb{E}[f(w_{t+1})] \le \mathbb{E}[f(w_t)] - \tfrac{1}{2\beta}\mathbb{E}\|\nabla f(w_t)\|^2 + \tfrac{1}{2\beta}\sigma^2$ (cross term vanishes by $\mathbb{E}[\xi_t]=0$).
- Telescope over $t$, bound by $f(w_1) - f^*$, average, and use Jensen/$\sqrt{a+b}\le\sqrt a+\sqrt b$ to pass from $\mathbb{E}\|\nabla f\|^2 \le \epsilon^2 + \sigma^2$ to $\mathbb{E}\|\nabla f\| \le \epsilon + \sigma$; get $T = O\big(\tfrac{2\beta(f(w_1)-f^*)}{\epsilon^2}\big)$.

**P4.2 (Bonus 7 pts).** Show a decaying learning-rate scheme $\eta_t$ guarantees an expected $\epsilon$-stationary point ($\min_{t\in[T]}\mathbb{E}\|\nabla f(w_t)\| \le \epsilon$), with the corresponding bound on $T$.
Key ideas:
- With $\eta_t \to 0$ (e.g., $\eta_t \propto 1/\sqrt{t}$ or $\eta_t = \min\{\tfrac1\beta, \tfrac{c}{\sigma\sqrt t}\}$), the noise term $\sum \eta_t^2\sigma^2$ grows slower than the signal term $\sum\eta_t$, so the averaged gradient bound tends to $\epsilon$ alone; solve for $T$ (typically $T = O(1/\epsilon^4)$).

**P4.3 (7 pts).** Let $\ell: \mathbb{R}^{d,d}\to\mathbb{R}$ be a $C^2$ convex loss overparameterized by a depth-$N$ linear network: $\phi(W_1,\dots,W_N) = \ell(W_N W_{N-1}\cdots W_1)$. Prove: (i) restricted to the product of unit balls $B^{d,d} = \{x : \|x\|\le 1\}$, $\phi$ is smooth (Lipschitz gradient); (ii) on the unrestricted domain, $\phi$ is smooth iff $\ell$ is constant, or $\ell$ is affine and $N = 2$.
Key ideas:
- (i) On a compact set, $C^2$ implies bounded Hessian, hence Lipschitz gradient.
- (ii) The product $W_N\cdots W_1$ is a degree-$N$ polynomial in the weights; its composition with a non-affine convex $\ell$ (or with affine $\ell$ but $N \ge 3$) has Hessian entries that grow unboundedly along rays (scale one factor), violating global smoothness; check the two exceptional cases directly (constant: trivial; affine with $N=2$: bilinear $\Rightarrow$ Hessian bounded... verify via explicit second derivatives).
- Take-away: deep overparameterization destroys global smoothness — guarantees must be local / restricted.

**P4.4 (Experiment, 7 pts).** Train a depth-$N$ linear network (hidden widths $\ge \min\{d_{\text{in}}, d_{\text{out}}\}$) on scalar regression with $\ell_2$ loss via full-batch GD, small LR and init. Plot objective, gradient magnitude, and max/min Hessian eigenvalues along the run; explain; repeat for $N = 2,3,4$.
Key ideas:
- Expect monotone loss decrease, gradient norm $\to 0$, $\lambda_{\min}(\nabla^2)$ negative early (saddle-dominated region, more so for deeper $N$) and $\to 0^-/0$ near convergence while $\lambda_{\max}$ stabilizes — illustrating the landscape results (no spurious local minima for linear nets, but non-convexity via indefinite Hessians).
