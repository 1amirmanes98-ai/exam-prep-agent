# FODL Exam Map
Recurring question archetypes across all indexed exams (see `index/exams/` for the full statements and solution sketches).

## Recurring question archetypes

1. **Piecewise-constant/linear characterization + universality** of a concrete activation class. **appeared in:** example_Q1, a2021_Q1, b2021_Q1, b2022_Q1, a2023_Q1, c2024_Q1

2. **Depth separation / expressive efficiency** (sawtooth-style or VC/counting; the b_2021 sitting is a negative result). **appeared in:** a2020_Q1, b2021_Q1, a2022_Q1, b2022_Q1, b2023_Q1, b2024_Q1

3. **Tensor/Kronecker expressiveness** **appeared in:** b2020_Q1, a2022_Q1

4. **Linear RNN hypothesis classes** (NEW in 2024; recitations and HW now cover SSMs — expect this to recur). **appeared in:** a2024_Q1, b2024_Q2

5. **GF on scalar/deep linear nets: balancedness + exponential convergence** (the b_2021 and c_2024 versions are nearly verbatim). **appeared in:** a2020_Q2, b2021_Q2, c2024_Q2

6. **GF on (symmetric) matrix factorization: dynamics + low-rank implicit bias** **appeared in:** a2021_Q2, b2023_Q2, a2024_Q2

7. **GF/landscape on shallow ReLU nets: conservation + sign preservation** **appeared in:** a2022_Q2, b2022_Q2

8. **NTK-style prediction dynamics** **appeared in:** b2020_Q2

9. **Hoeffding + union bound over finite/quantized class, then SRM/weighted refinement** **appeared in:** a2021_Q3, b2023_Q3, a2024_Q3, b2024_Q3, b2020_Q3

10. **Covering/discretization bounds (Lipschitz transfer)** (the a_2023 and c_2024 versions are nearly identical). **appeared in:** a2023_Q3, c2024_Q3

11. **Implicit bias of GD → min-norm + norm-based/Rademacher bound** **appeared in:** a2020_Q3, b2021_Q3, b2022_Q3

12. **PAC-Bayes** **appeared in:** a2022_Q3, example_Q3
